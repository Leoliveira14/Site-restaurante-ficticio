# Japa Portugal — site de demonstração

Site responsivo de restaurante em um único HTML. Para abrir localmente, basta abrir `index.html` em um navegador; não precisa instalar dependências.

## Conteúdo

- Página principal em português de Portugal.
- Rodízio apresentado sem afirmar regras, preços ou pratos oficiais.
- Carta fictícia de demonstração dentro do HTML.
- QR code para a carta online e link direto para a demonstração.
- Links para WhatsApp, telefone, Maps e Instagram.
- Logotipo vetorial inspirado na referência enviada.
- Efeitos de vapor decorativo, com suporte a movimento reduzido.

As fotografias e os itens da carta são ilustrativos. Fontes, algumas imagens e serviços externos exigem internet.
